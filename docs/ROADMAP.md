# WII-001 — Staged Roadmap

**Status: PROPOSED. No feature is considered delivered until implementation and verification evidence exist.**

## Stage 0 — Preservation and inventory
- Preserve existing Worldview globe/app, prior prototypes, relevant GIS and infrastructure tools, and shared KCN/MANIFEX capabilities before composition.
- Build a complete source inventory and lineage manifest.
- Review licenses, secrets, dependencies, tests, security and data rights.

## Stage 1 — Product and domain contracts
- Freeze platform boundaries, system register, asset identity model, location model, evidence/provenance contract, access model and temporal history rules.
- Define stable IDs and interoperable API/event contracts.
- Define data states and UI evidence semantics.

## Stage 2 — Map foundation
- Establish 2D/3D navigation, coordinate reference handling, map layer registry, search, location hierarchy and selectable asset model.
- Reuse preserved globe components only after isolated tests and rendering checks.
- Add a bounded pilot geography with lawful base data and explicit coverage metadata.

## Stage 3 — Document and asset intelligence
- Source registry and jurisdiction inventory.
- Original document intake, integrity, OCR/PDF/CAD/GIS extraction, document viewer, revision history.
- Pole, manhole, vault, conduit, cable, underground utility and residential asset models.
- Document-to-map association and reconstruction review.

## Stage 4 — Construction and field operations
- Projects, contractors, crews, work events, daily records, as-built submissions.
- Inspection authority registry, inspections, deficiencies, corrections and reinspection.
- Rod/sonde/mandrel pathway investigations and field-to-map observations.
- Schedule and delay intelligence with documented causality.

## Stage 5 — Quality, recognition and professional history
- Context-adjusted construction performance metrics.
- Evidence-based recognition and fair correction/dispute handling.
- Worker-controlled professional infrastructure passport.

## Stage 6 — National source intelligence and monitoring
- Federal, state, county, city, tribal, district and private-custodian source registry.
- Utility-specialist research workstreams, independent verification and multidimensional coverage reporting.
- Continuous source monitoring with explicit unavailable/unchecked/no-change states.

## Stage 7 — Scale and independent qualification
- Security review, load/performance testing, disaster recovery, data governance, legal/access review, independent verification and human ratification where required.
- Expand geography and utility categories only as evidence and operations support.
