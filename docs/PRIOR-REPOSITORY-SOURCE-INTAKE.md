## Intake rules

- The WII repository is the destination; source repositories remain unchanged.
- Clone the exact branch/commit before using source code, data, prompts, schemas, capabilities or tooling.
- Do not copy an entire large ecosystem blindly. Identify the WII-relevant components, preserve their original paths and lineage, then assess security, license, dependencies, overlap and tests.
- The KHGSI and MANIFEX repositories are private. Preserve their access boundaries; do not publish private code or secrets into this public WII repository.
- A repository's existence or size is not evidence that a capability works.
- Keep a record of inspected paths, excluded paths, missing files, exact commit, blob hashes and verification status.
